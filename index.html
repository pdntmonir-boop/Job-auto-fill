Phone Bookmark ফোনের বুকমার্ক

আপনার Chrome-এ বড় বুকমার্ক চলে না। তাই ফিল-ইঞ্জিন একবার GitHub-এ রাখতে হবে (ফ্রি, এতে কোনো ব্যক্তিগত তথ্য নেই)। বুকমার্কে শুধু আপনার তথ্য আর ছোট লোডার থাকবে।

ধাপ ১: ইঞ্জিন GitHub-এ রাখা (শুধু যে ইঞ্জিন বানাচ্ছে তার জন্য, বন্ধু এটা বাদ দেবে)
  1. নিচের Copy engine চাপুন।
  2. github.com-এ লগইন করে আপনার বর্তমান Job-auto-fill repository-তেই gj.js ফাইল রাখুন।
  3. Add file → Create new file → নাম gj.js → কপি করা লেখা পেস্ট → Commit changes।

ধাপ ২: ইঞ্জিনের লিংক (দেওয়া আছে, বদলাতে হবে না)

আপনার Job-auto-fill repository-এর Engine URL আগে থেকেই দেওয়া আছে। URL পরিবর্তন করবেন না, যদি repository বা ফাইলের অবস্থান না বদলান।

ধাপ ৩: বুকমার্ক কোড

উপরে তথ্য দিয়ে "Create Phone Bookmark" চাপুন। কোড তৈরি হবে।

  1. Chrome-এ যেকোনো পেজ ⋮ মেনু থেকে ☆ দিয়ে বুকমার্ক করুন।
  2. ⋮ → Bookmarks → ওই বুকমার্ক → Edit। Name: AF   URL: পুরোনোটা মুছে কোডটা Paste করুন → Save।
  3. সরকারি ফর্ম খুলে অ্যাড্রেস বারে AF লিখুন, সাজেশনে বুকমার্ক-আইকনওয়ালা AF-এ ট্যাপ করুন।
  4. নিচে আসা প্যানেলে Autofill চাপুন। তথ্য বদলালে নতুন কোড বানিয়ে বুকমার্কের URL বদলান। ইঞ্জিন আর বদলাতে হবে না।
